Descrição da aplicação

O objetivo do projeto foi aplicar conceitos de HTML5 e CSS3 na construção de uma interface responsiva, utilizando o framework Bootstrap como base de estilização e componentes.
A proposta foi construir uma experiência de navegação simples e intuitiva, aplicando boas práticas de estruturação de layout e responsividade.
Nós utilizamos para o arquivo o que foi aprendido em aula:
HTML5
CSS3
Bootstrap
Font Awesome

E para a estrutura de páginas:
index.html — página inicial, com carrossel de destaques e categorias de produtos.
categoria.html — listagem de produtos com filtros por preço, tipo e marca.
produto.html — página de detalhes de um produto específico.
contato.html — formulário de contato com a loja.
style.css — arquivo de estilos personalizados do projeto.
IMG/ — pasta com as imagens utilizadas no site.

Responsividade:
Todas as páginas foram pensadas para se adaptar a diferentes tamanhos de tela, com a responsividade já transmitida do Bootstrap.
A grade de categorias foi construída com CSS Grid, também foi adaptada por meio de media exibe quatro colunas em telas grandes, reduz para duas colunas em telas médias
para garantir uma boa leitura do conteúdo em qualquer dispositivo.

Componentes do Bootstrap:
Para os componentes do Bootstrap, nós usamos pra garantir um suporte em telas menores, exibição dos banners
e a apresentação dos produtos e categorias, juntamente para o modelo de Formulário estilizado na parte do contato.
(Navbar, Carousel, Cards, Formulários estilizados e Botões padronizados).

A biblioteca Font Awesome também foi incorporada ao projeto para os ícones utilizados na navegação, nos botões de ação e nas redes sociais do rodapé.

As cores principais do projeto foram definidas por meio de variáveis CSS, o que facilita a manutenção e garante consistência visual entre as páginas.
A paleta escolhida é composta por tons de verde, remetendo à natureza e à sustentabilidade, combinados com um fundo neutro em tom bege.
